# 🧠 Customer Churn Prediction Model

This project focuses on building a **machine learning model** to predict customer churn using the **Telco Customer Churn dataset**.  
The aim is to identify customers who are most likely to leave, helping businesses take proactive retention measures.

---

## 📂 Project Structure

| File | Description |
|------|--------------|
| `Churn_model.ipynb` | Main Jupyter Notebook containing all the steps of the ML pipeline |
| `WA_Fn-UseC_-Telco-Customer-Churn.csv` | Dataset used for training and evaluation |

---

## 🧰 Technologies & Libraries Used

- 🐍 **Python 3.x**
- 📦 **NumPy** – Numerical computation  
- 📊 **Pandas** – Data manipulation  
- 🎨 **Matplotlib & Seaborn** – Visualization  
- ⚙️ **Scikit-learn** – Preprocessing, modeling, and evaluation  
- ⚖️ **Imbalanced-learn (SMOTE)** – Handling class imbalance  
- 🚀 **XGBoost** – Advanced boosting model  
- 💾 **Pickle** – Model serialization
